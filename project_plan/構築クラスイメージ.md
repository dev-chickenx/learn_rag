# RAGの構築クラスイメージ

Phase2まで作成してDBのない状態である程度適切なクラス構成を作成できた。
実際にはキャッシュではなくDB化したりするので、このあたりを考慮したより実用的なRAG構成を記載する。

7/5時点では実装していないので、あくまでイメージである。

## 1. DBを含めたRAGのイメージ

## 2. クラスとして機能を分割してみる

### 一番荒い初期のイメージ

クラス間の依存

```mermaid
classDiagram
  class DocumentLoader {
    +Path source
    +Iterable[Doc] load()
  }
  class Chunker {
    +int size
    +int overlap
    +Iterable[str] chunk(Doc)
  }
  class Embedder {
    +EmbeddingModel model
    +np.array embed(list[str])
  }
  class VectorStoreWriter {
    +VectorDB client
    +void upsert(vectors, metadata)
  }

  class QueryEmbedder {
    +Embedder embedder
    +np.array embed(str query)
  }
  class Retriever {
    +VectorDB client
    +int top_k
    +list[Chunk] search(np.array vec)
  }
  class Reranker {
    +LLM model  (*optional*)
    +list[Chunk] rerank(chunks, query)
  }
  class PromptBuilder {
    +str build(chunks, query)
  }
  class AnswerGenerator {
    +LLM model
    +str generate(prompt)
  }

  class FeedbackLogger {
    +void log(query, answer, rating)
  }

  DocumentLoader --> Chunker : feeds
  Chunker --> Embedder : sends text
  Embedder --> VectorStoreWriter : vectors
  QueryEmbedder --> Retriever : vector search
  Retriever --> Reranker
  Reranker --> PromptBuilder
  PromptBuilder --> AnswerGenerator
  AnswerGenerator --> FeedbackLogger : user rating


```

### クラス化

```mermaid
classDiagram
    %% ======== Embedding 基盤 ========
    class EmbeddingClient {
        +embed(texts) list[vec]
        -api_key str
        -model   str
    }

    class IngestEmbedder {
        +embed_many(texts) list[vec]
        -bulk_size int
    }

    class QueryEmbedder {
        +embed(query) vec
        -cache LRUCache
    }

    IngestEmbedder *-- EmbeddingClient
    QueryEmbedder  *-- EmbeddingClient

    %% ======== Ingest パイプライン ========
    class DocumentLoader {
        +load() Iterable[Doc]
    }
    class Chunker {
        +chunk(doc) Iterable[str]
        -size int
        -overlap int
    }
    class VectorStoreWriter {
        +upsert(vecs, meta)
        -client VectorDB
    }
    class IngestPipeline {
        +run()
        -loader  DocumentLoader
        -chunker Chunker
        -embedder IngestEmbedder
        -writer  VectorStoreWriter
    }

    IngestPipeline o-- DocumentLoader
    IngestPipeline o-- Chunker
    IngestPipeline o-- IngestEmbedder
    IngestPipeline o-- VectorStoreWriter

    DocumentLoader ..> Chunker
    Chunker        ..> IngestEmbedder
    IngestEmbedder ..> VectorStoreWriter

    %% ======== Query パイプライン ========
    class Retriever {
        +search(vec) list[Chunk]
        -client VectorDB
        -top_k int
    }
    class Reranker {
        +rerank(chunks, query)
        -model LLM
    }
    class PromptBuilder {
        +build(chunks, query) str
    }
    class AnswerGenerator {
        +generate(prompt) str
        -model LLM
    }
    class FeedbackLogger {
        +log(query, answer, rating)
    }
    class QueryPipeline {
        +answer(query) str
        -q_embedder QueryEmbedder
        -retriever  Retriever
        -reranker   Reranker
        -prompt_builder PromptBuilder
        -generator AnswerGenerator
        -logger    FeedbackLogger
    }

    QueryPipeline o-- QueryEmbedder
    QueryPipeline o-- Retriever
    QueryPipeline o-- Reranker
    QueryPipeline o-- PromptBuilder
    QueryPipeline o-- AnswerGenerator
    QueryPipeline o-- FeedbackLogger

    QueryEmbedder  ..> Retriever
    Retriever      ..> Reranker
    Reranker       ..> PromptBuilder
    PromptBuilder  ..> AnswerGenerator
    AnswerGenerator..> FeedbackLogger
```
